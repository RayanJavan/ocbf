# Research corpus

These dated investigations, proposals, and planning records are retained for their
scientific reasoning and provenance. Their original status and implementation snapshots
are preserved. They are not the current library specification and are excluded from the
documentation build, search index, and machine-readable site.

For current behavior, use the [library documentation](../docs/index.md) and
[current architecture](../docs/development/architecture.md).

| Material | Purpose |
|---|---|
| [Grounding synthesis](ocbf-grounding-synthesis.md) | Semantic foundations, primary literature, and dated source inspections. |
| [Grounding proposal](ocbf-grounding-proposal.md) | Proposed evidence and temporal semantics. |
| [Inference synthesis](ocbf-inference-synthesis.md) | Algorithm comparisons and numerical qualifications. |
| [Inference proposal](ocbf-inference-proposal.md) | Proposed inference and query contracts. |
| [Software architecture proposal](ocbf-software-architecture.md) | Original architectural recommendation and inspected source baseline. |
| [Refactoring plan](ocbf-refactoring-plan.md) | Original delivery scope and acceptance criteria. |
| [Research notes](research-notes.md) | Earlier literature and formal analysis. |
| [Mammut source register](mammut-source-register.md) | Dated source hashes, provenance findings, and admission limitations. |

Relative links within the corpus should remain readable from the repository. References
to removed implementation snapshots are historical evidence, not instructions to use
an unavailable API. Research statements are not automatically current capability claims.

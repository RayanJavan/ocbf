# Reference

Use these pages for precise supported behavior. API pages below this section are generated
from the explicitly documented modules.

- [Capabilities and limitations](capabilities.md): engines, channels, and process queries.
- [Configuration and errors](configuration.md): policy defaults, budgets, and failure meanings.
- [Results and interchange](results.md): values, qualifications, denominators, and retention.
- [Glossary](glossary.md): consistent terminology.
- [API reference](api/index.md): callable contracts grouped by responsibility.

The API navigation has two tiers. **Workflow and contracts** leads with the facade and the
scientific contracts. **Numerical and source utilities** are grouped separately because a
low-level marginal interface does not imply a process-query capability.

# Glossary

| Term | Meaning |
|---|---|
| Semantic skeleton | Fixed domain types, qualified relations, and assertion meanings. |
| Candidate universe | Explicit bounded possibilities on which inference is conditioned. |
| Assertion reference | Stable semantic address, separate from dense execution indices. |
| Evidence record | Retained report envelope with identity, provenance, timing, and revision action. |
| Snapshot | Effective reports under a declared materialization policy and cutoff. |
| Knowledge time | When information becomes available to an analysis. |
| Validity time | When the reported occurrence or condition applies. |
| Interpreter | Versioned mapping from understood reports to observations and admission issues. |
| Observation channel | Probability semantics for a report under possible truths and supplied parameters. |
| Information group | Declared ownership of one information contribution, including known copies. |
| Manual trust | Explicit channel assumptions resolved before inference. |
| Channel sensitivity | Probability of a positive report when the modeled assertion is true; distinct from the posterior probability that a report is correct. |
| False-positive probability | Probability of a positive report when the modeled assertion is false. |
| Canonical model | Engine-independent variables, factors, support, decoding, and scientific identity. |
| Support | States permitted by candidates and definitional constraints. |
| Normative reference | Criterion evaluated against descriptive belief, not silently imposed on it. |
| Posterior capability | An operation the retained representation can actually provide. |
| Joint draw | Coherent state assignment preserving the model's shared uncertainty. |
| MCSE | Monte Carlo standard error for a specified estimated quantity. |
| Source-evidence ESS | Dependence diagnostic for static source evidence; not MCMC precision. |
| Monte Carlo ESS | Autocorrelation-based sampling diagnostic; not physical evidence quality. |
| Assumption sensitivity | Differences between answers under named parameter/model assumptions, without implied mixture weights. |
| Exposure | Descriptive overlap of a projected interval with supplied condition intervals. |
| Warm start | Validated initialization hint for fresh computation on a revised target. |
| Replay | Recalculation from recorded scientific inputs and declared implementations. |

[Parameters and trust](../concepts/parameters.md) distinguishes channel sensitivity from
assumption sensitivity. [Queries and result meaning](../concepts/queries.md) relates
posterior uncertainty, numerical error, and evidence limitations to concrete results.
